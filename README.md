# ModelPrimer
ModelPrimer is an open-source cross platform 3D texture painting software that employs the use of realtime lighting to create physically accurate models.

## Why use ModelPrimer?
ModelPrimer is a lightweight tool that supplements your modeling and rendering pipeline. This software will allow you to directly paint textures onto your models while viewing your changes in a realtime rendering simulation. This software works exclusively with texturing and rendering, so you won't have to be bothered by any of the clutter in your 3d application. Simply upload your object file and get painting!

## Installation
There are two methods for downloading the project on your machine. There is no code or executable to run at the moment, so no build is required.
### Method 1: Clone the repository
You may clone the repository to your machine either by using the clone command in GitHub Desktop, or by using the following Command Line instruction:
~~~
git clone https://github.com/NAU-OSS/ModelPrimer.git
~~~
### Method 2: Download zip file
You may also download a zip file directly from the repository website on GitHub. Simply go to the "Code" tab in GitHub and select "Download Zip". From there, you can unzip the project into its own folder.
